## 三、构建策略

- qemu 只编 user-mode 的 aarch64-linux-user 目标：--disable-system，构建量最小。
- meson/ninja 经 python3 -m pip install --user 安装，不污染系统。
- 构建产物落在项目内 build/，卸载整目录删除即可，无系统残留。
